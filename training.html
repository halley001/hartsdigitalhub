FAQ

Quick questions

Is the course free?

Yes. All 7 modules and the certificate are free. You sign in with your email; there is no password and no card.

What do I need before I start?

A computer running Windows, macOS or Linux, an internet connection, and a free GitHub account. No programming experience is needed.

Why SSH keys instead of a password?

GitHub no longer accepts your account password for pushing code. An SSH key, set up once, lets every push and pull through without typing anything, and the private key never leaves your computer.

How do I verify a certificate?

Every certificate carries an ID like HDH-GIT-XXXXXXXX. Message us the ID on WhatsApp via the verification page and we'll confirm it directly.
